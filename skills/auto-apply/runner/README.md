## Escalation ladder — how to run (2026-10-28)
- Claude-attended (recommended while the ladder is new): Claude in Chrome (installed in the job Chrome, signed in) opens a tab `https://example.com/?cx=<name>`, then on the Mac: `~/.job-agent-venv/bin/python -u run.py "<app>" --attach cx=<name> [--submit]`. On `STATUS handoff`, Claude fixes the fields in `<app>/handoff.json` in that same tab, then `run.py "<app>" --resume --attach <greenhouse token or marker> [--submit]` (re-verify only, no refill).
- Unattended: without `--attach` run.py opens its own tab; a handoff leaves that tab open and is queued — Claude reruns with `--attach` in a Claude tab (the extension can only control tabs in its own tab group).
- Fields not on this form: optional ones and generic profile fields (`…--0`, e.g. education dates on Faraday) are logged as skipped and saved in `<app>/runtime.json` (used by `--resume`).
- `page.set_default_timeout(8000)`: a click blocked by an overlay fails fast instead of hanging.
- Confirmation = Greenhouse `/confirmation` URL or thank-you text that was not on the page before the click.
- plan_build also reads the API's `demographic_questions` (Gender Identity, Race/Ethnicity, Pronoun, Sexual Orientation; some boards make them required).
- Keep the job Chrome free of other extensions (Simplify's popup blocked all clicks on 10-28; Joey disabled it).
- Batch 1 (10-28): DeepSeek fixed DV (83-option checkbox group), Jump (acknowledgement checkbox), a Greenhouse employer (Languages) in one try each, ~7.4k tokens total; level 3 (Claude handoff) not yet needed/tested on a live form.

# Application-form answers: "are you local to <place>?" and website-password boxes — spec (2026-11-04)

The candidate lives in Chicago, IL (home city). He is willing to relocate anywhere in the U.S. for a summer internship and
accepts on-site and hybrid work. He is NOT local to any other city or region.

1. A question asking whether the candidate is local to a place ("Are you local to NYC or the Tri-State area…", "Is you
   local to the Boston area?", "Are you currently local to our Austin office?", "Are you local to the Seattle region?"):
   - If the named place is Chicago / Chicagoland → the "Yes" option (or the text "Yes" when there are no options).
   - Any other place → the option that says the candidate is not local but willing to relocate (e.g. "No, but willing to
     relocate to NYC"); never an option saying he is local, and never one saying he cannot / is not able to / is unwilling
     to relocate. If no such relocate option exists → the "No" option (or the text "No" with no options).
   - This holds even when the question also mentions commuting, hybrid or in-office schedules.
2. A text box asking for a website / portfolio PASSWORD ("Portfolio, Video, or Website Password", "Website password (if
   protected)") is never filled with the candidate's website URL → expect "none" (left for a human / left blank).
3. A plain website / portfolio LINK box ("Portfolio, Video, or Website Link", "Personal website", "Portfolio URL") still
   gets the candidate's website: https://github.com/alex-doe-example
4. Questions that ask about willingness only, with no "local to" wording ("Are you able to work on-site in NYC 3 days a
   week?", "Are you willing to relocate?") → "Yes".

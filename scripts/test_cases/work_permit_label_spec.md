# Is this form question the yes/no question "Do you have a valid work permit"?

An answer audit checks one kind of question: a yes/no question asking whether the applicant HAS a valid work permit in
the country of the position (expected answer for him: "Yes"). Given a question label, say whether it is such a question
(true) or not (false).
True: "Do you have a valid work permit for the country where this position is located?", "Valid work permit?",
"Do you hold a work permit in the U.S.?".
False: questions that ask for free-text details, type, expiry date or description of a work permit or visa
("Please provide details re: your current work permit or visa (type and expiry)", "Describe your work permit",
"What type of work permit do you hold?", "Work permit expiry date"), and questions that do not mention a work permit.

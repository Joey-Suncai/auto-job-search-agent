# Workday: when is the page Review, and did Save and Continue take effect? (JSA-071)
Functions:
1. is_review_page(step, fields) -> bool. step = the progress bar's current-step text (may start with "current step N of M"; Chinese tenants show e.g. "当前步骤 8/8审查"); fields = the form fields now on screen, each {"type": ...}. True only when the step is a Review step (English "Review", Chinese 审查/审阅/審查/審閱/检查/確認, also words starting Revis / Überprüf / Examen / Riepilogo) AND no field other than type "file" is on screen. "Voluntary Disclosures", "My Information", "Application Questions", "Self Identify", "" are never Review. A step that only contains the word review later ("Pre-Review Questions" is not a review step because the step must START with the review word after the "current step N of M" prefix).
2. step_changed(before_step, before_keys, after_step, after_keys) -> bool. keys = ids of the fields on the page (a new page has new ids). True only when after_step is non-empty, differs from before_step, and the page does not still show exactly the same set of field ids as before (when before_keys is non-empty). Empty after_step (loading) = false. Same step = false. Different step but identical non-empty key set = false (the old page is still shown). before_keys empty = only the step decides.

# Fixed application-form answers confirmed by the candidate on 2026-11-01

An answer-rule engine maps a form question (label, field type, options) to one answer. For a select, the answer must be
one of the options, copied exactly.
- Willing to submit to a background check, background screen, background investigation and/or drug screen / drug test → "Yes".
- Has a valid U.S. driver's license / driver license / driving licence → "Yes".
- "What is your preferred work arrangement?" (also "preferred working model / mode / environment", "Which work
  arrangement would you prefer?") when only ONE option can be chosen → the on-site / in-office option (e.g. "Onsite
  (in-office)", "On-site", "In office"), never a hybrid or remote option.
- "Phone Device Type" → the mobile / cell option ("Mobile", "Cell", "Personal Cell Phone", "Mobile Phone"), never
  "Landline", "Home" or "Work".
Questions outside these patterns are not part of this test; do not include them.
- "Please provide the State and Class for your driver's license" → "Illinois, Class D" (Joey 2026-11-01).

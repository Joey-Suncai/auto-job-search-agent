# Workday experience page that shows no fillable fields (JSA-065)
Function: zero_field_experience(sections, upload_ok, body_text) -> "error" | "resume-only" | "empty".
Called only when the runner planned 0 fillable fields on a "My Experience" page. sections = the headings of the page's sections (e.g. "Work Experience", "Education", "Languages", "Resume/CV", "Websites"); upload_ok = a résumé upload shows as successful; body_text = the visible page text.
- "error" when the page text shows a Workday error: "Something went wrong", "session expired" / "session has expired" / "session timed out", "an error occurred" / "an error has occurred", "page not available" / "page is unavailable" (case-insensitive). This wins over everything else (an old draft / expired session — rerun fresh, then the candidate withdraws the draft).
- "resume-only" when there is no error, the résumé upload is successful, and none of the sections is a work / employment / experience / education / academic / school / language section. A section whose heading names the résumé, CV, curriculum vitae or attachments does not count as such a section even if it also contains one of those words (e.g. "Resume/CV", "Attachments"). Other headings like "Websites" or "Social Network URLs" do not count either. No sections at all + upload successful = "resume-only".
- "empty" otherwise: a work / education / language section exists but nothing rendered, or the upload is not successful. The runner then stops and never advances unchecked.

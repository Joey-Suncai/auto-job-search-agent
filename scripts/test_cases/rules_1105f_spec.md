# Spec: "Are you ON OPT?" vs. work authorization that names OPT only as an example (2026-11-05, Goldman Oracle)

The candidate: F-1 student, legally authorized to work in the U.S. for the Summer 2027 internship (on CPT through his
school). He is NOT on OPT now and has never been. He does not need sponsorship now (internship) but will in the future.

1. **Work-authorization question with OPT / CPT only as an example → Yes.** The question asks whether he is authorized /
   eligible / able to work (or holds or can obtain valid work authorization), and OPT appears only inside an example:
   "(e.g., …)", "(such as …)", "(for example …)", a parenthesised list "(U.S. citizen, green card, OPT, etc.)", or an
   "e.g. …" clause — also when the example group contains its own parentheses, e.g. "Are you legally authorized to work
   in the United States? In other words, do you currently hold or can you obtain valid US work authorization (e.g.,
   currently hold H-1B status, or can commence employment based on F-1 Optional Practical Training (OPT))?" → **Yes**.
   Never No (that would say he cannot work).
2. **A question that really asks whether he is ON OPT → No.** "Are you currently on OPT?", "Are you on STEM OPT?",
   "Are you currently working on F-1 Optional Practical Training (OPT)?", "Is your current work authorization OPT?" → No.
   Only such questions get the OPT answer; a question with OPT only in an example (rule 1) never does.
3. **Without sponsorship** ("Are you able to work in the U.S. without sponsorship? (e.g., OPT, CPT)"): the sponsorship
   answer flipped — only now / this internship → Yes; also the future ("now or in the future", "at any time", "after
   graduation") → No.

Options are ["Yes", "No"] (any order) unless a case says otherwise.

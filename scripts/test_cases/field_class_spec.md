# Critical vs non-critical application-form questions (decided by the candidate 2026-11-05)

"Important information must never be wrong; non-important information must be right at least 95 % of the time."

A question (its label as the form shows it) is CRITICAL when it asks about:
1. work authorization, sponsorship, visa type / status, citizenship, permanent residence, immigration, work permit,
   CPT / OPT / H-1B, export-control "U.S. person" questions → group work_auth;
2. his school, degree, major / field of study / minor, GPA, enrollment, class standing, transcript, degree start or
   graduation dates, the start / end month or year of an education or work-history entry → group education;
3. his own name, e-mail, phone, street address, ZIP / postal code, city or state of residence, date of birth → group contact;
4. EEO / self-identification: gender, sex, race, ethnicity, Hispanic / Latino, disability, veteran / military status,
   pronouns, sexual orientation, transgender → group eeo;
5. anything written as his experience or as other people's contact details: work history, employer, job title, years of
   experience, descriptions of his projects or work, references / referees, portfolio / GitHub / LinkedIn → group experience.

Everything else is NON-CRITICAL (group ""), in particular: how did you hear about us / source, communication
preference (e-mail / SMS / WhatsApp), salary / pay / compensation expectations, available or desired START DATE for the
job, location / office / relocation / remote / hybrid / on-site / travel preferences, consent checkboxes, optional
questions, relatives employed at the company, "why do you want to work here" style motivation questions.

Precedence: a question that mentions work authorization / sponsorship / visa is critical work_auth even if it also
mentions location or start dates. A question about the job's start date or location stays non-critical even if it
mentions a city or a date. "Start date year" / "End date year" / "From month" with nothing else are the dates of an
education or work entry → critical education.

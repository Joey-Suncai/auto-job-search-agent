# Workday "How did you hear about us" — choosing a truthful option (JSA-067)
Functions: source_pick(options) -> one option string or null; real_options(options) -> list.
- real_options drops empty strings and placeholders: "Select One", "Select", "Choose One", "--", and the Chinese placeholders "选择一个", "请选择", "請選擇", "選擇一個" (case-insensitive, an optional trailing period). Everything else is kept in order. An empty result means the tenant's list is empty.
- source_pick never returns a placeholder and never returns an option that claims a person, contact, job or event the candidate never had: any option mentioning alumni, referral/referred, employee, recruiter/recruiting (but "zip recruiter"/"ZipRecruiter" is a job board and allowed), friend, family, colleague, career fair, job fair, campus, event, conference, university, college, school, professor, agency, search firm, staffing, direct contact, contacted, headhunter, sourcer, contingent, contractor, temporary/temp, in-person, program, workshop, info session / information session, alma mater.
- Among the allowed options, neutral channels come first: options mentioning website, career site, job board, online, internet, social, LinkedIn, Indeed, Glassdoor, search engine, Google, or starting with the word "Other". Ties keep the original order. If no neutral option exists, the first allowed option in list order is returned.
- If no option is allowed, source_pick returns null (the runner then stops and asks the candidate; it never falls back to a claim).

# Two yes/no form questions answered from fixed facts

Facts: the candidate has never worked, studied or been known under any other name (answer No). He holds no professional
licenses of any kind — no insurance / producer license, no real-estate license, no securities (FINRA, Series 7/63/65 …)
license (answer No). (He does hold an Illinois driver's license, which is a different question.)

Classify each question label as:
- "other_name": asks whether he has worked / been employed / attended school / been known under another, other, different,
  former, previous or maiden name, or used any other name — including misspelled forms like "Have you even been employed
  under any other name?".
- "license": asks whether he holds an insurance, producer, real-estate, securities, FINRA or Series-N license.
- "neither": anything else — e.g. "Preferred name", "Legal name", "Do you have a valid driver's license?", "What name should we
  call you?", "Name of your manager", "List any certifications".

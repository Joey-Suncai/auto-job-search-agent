# Phone device type answer (application forms, mostly Workday "My Information")

A form question labelled "Phone Device Type" (or "Device Type", "Phone Type", "Phone Device Type*") asks what kind of
phone the candidate's number is. The candidate's number is a mobile (cell) phone.

Rules:
1. When the options include a mobile / cell phone option, pick it. Mobile wordings: "Mobile", "Mobile Phone",
   "Cell", "Cell Phone", "Personal Cell Phone", and any option containing the word "Cellular" (e.g. "Cellular",
   "Home Cellular", "Personal Cellular", "Work Cellular").
2. An option that contains "Cellular" is a mobile phone even when it also says "Home" — "Home Cellular" is preferred
   over plain "Home".
3. Never pick a plain "Home", "Landline", "Work", "Fax", "Pager" or "Other" option when a mobile / cell / cellular
   option exists.
4. When several mobile options exist, an option that is exactly "Mobile" wins; otherwise one starting with "Cell";
   otherwise one containing "mobile"; otherwise one containing "cell" as a word; otherwise one containing "cellular".
   Among equals, the first in the list wins.
5. When the options contain no mobile / cell / cellular option at all (e.g. only "Home", "Work", "Landline"), the
   answer is UNKNOWN (the question goes to the candidate) — never guess "Home".
6. Matching ignores case and leading/trailing spaces.
7. A text box (no options) with this label gets the text "Mobile".
